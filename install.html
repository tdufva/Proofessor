Install

Download the standalone macOS app, place it in Applications, and choose what it may scan on first launch.

Download macOS app Download source Checksums
  1. Download Proofessor-macOS.zip.
  2. Open the zip file and move Proofessor.app to Applications.
  3. Open the app. On first launch it creates ProofessorWorkspace in Documents.
  4. Add evidence files to the workspace, or choose extra folders in Source Settings.
  5. Run Deep Scan to import reviewable candidates.

For public distribution, use a Developer ID signed and notarized build. Unsigned private-test builds may require Control-click and Open on first launch.

The clean source package is available as Proofessor-source.zip.
