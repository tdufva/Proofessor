Getting Started

  1. Download and open Proofessor.
  2. Open Start Here.
  3. Choose one folder that contains tenure, CV, teaching, publication, project, or service material.
  4. Run the deep scan across that folder and its subfolders.
  5. Review the three sample suggestions first so the workflow is clear.
  6. Export the tiny demo CV to see what the app is building toward.

How The App Works

1. It keeps a private workspace

On first launch, Proofessor creates a clean workspace in Documents. This workspace stores app records, suggestions, exports, and source traces. Keep the workspace private and share only intentional exports.

2. It scans existing material

The app can inspect the workspace, inbox, chosen folders, subfolders, PDFs, text files, CV source files, BibTeX, DOI snippets, course feedback, folder names, and profile links where possible.

3. It creates suggestions, not final claims

Scanned material becomes reviewable suggestions. Nothing becomes dossier evidence until the user accepts or edits it.

4. It exports from confirmed evidence

CVs, bios, narrative paragraphs, readiness reports, and dossier packets are built from the approved record set so the output is easier to review and defend.

Review Evidence

  1. Select one or more suggestions in the review inbox.
  2. Read the Aalto dimension, confidence, why suggested, proof found, and what is missing.
  3. Open Why the app found this to see the exact file, folder, date, text snippet, and source link.
  4. Accept, edit, dismiss, merge duplicates, or mark proof needed.
  5. Only move material into the evidence base when it is clear enough to support a claim.

Aalto Criteria

Proofessor uses Aalto-style dimensions as a review lens, including research or artistic work, teaching, impact, service, leadership, and recognition. Choose the school and career-stage preset that best matches the case, then adapt the final dossier to the official local call.

Autofill Profile

  • Use Autofill My Profile after adding profile links or CV files.
  • Review name, title, affiliation, research themes, artistic themes, teaching themes, ORCID, Scholar, Aalto profile, selected publications, and selected projects.
  • Edit anything that is incomplete or wrong.
  • Use the profile as the shared base for CVs, bios, public profiles, and dossier paragraphs.

CVs, Bios, Dossiers

  • Open Build CV and choose the purpose: Aalto/TENK formal, elegant academic, research, artistic portfolio, teaching, compact two-page, or public profile.
  • Use export preview to check typography, spacing density, section order, page count, and length warnings.
  • Use Bios for academic, artistic, research, teaching, public-profile, and speaker-introduction versions.
  • Use short, long, or custom character-limited bio lengths, then edit before sharing.
  • Use Dossier Builder for evidence-backed paragraphs about research or artistic work, teaching, impact, service, future trajectory, leadership, and international recognition.

Signing

  1. Download the source package.
  2. Open TenureEvidenceApp/Proofessor.xcodeproj in Xcode.
  3. Select the Proofessor target.
  4. Open Signing & Capabilities.
  5. Choose your Apple Developer team and keep Hardened Runtime enabled for public distribution.
  6. Archive or export from Xcode, or use the included notarization script after your Developer ID certificate is installed.
