# Install Notes

1. Download `Proofessor-macOS.zip`.
2. Open the zip file and move `Proofessor.app` to Applications.
3. Open the app. On first launch it creates `ProofessorWorkspace` in Documents.
4. Add evidence files to the workspace, or choose extra folders in Source Settings.
5. Run Deep Scan to import reviewable candidates.

If macOS blocks the app because it was downloaded from a website, the app needs Developer ID signing and notarization before public distribution. For private testing, users can Control-click the app and choose Open.

The source package is available separately as `Proofessor-source.zip`.
